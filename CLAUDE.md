# Working rules for this project (Project Smart Layer by Azam Puri)

## Rule 1 — Discuss and finalize first, then build once
- Do NOT start coding until the full plan is discussed with the user and explicitly approved.
- Finalize all requirements, design decisions and open questions up front, then build everything together in one pass.
- Avoid building, rebuilding and re-building piecemeal — it wastes tokens and time. Lock the design, then implement.
- Wait for a clear "go" before writing code.

## Rule 2 — Be concise
- Keep replies short and to the point. Go long only when the user asks for detail.

## Context
- Address the user as "Sir Azam Puri sb".
- The app is a product sold to many textile weaving mills (ERP-agnostic), not just Dost Textiles — keep everything generic; mill-specific details live in mapping files and config, never in the core code.
